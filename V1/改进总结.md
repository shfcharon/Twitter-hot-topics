# V1 Pipeline 改进总结

## 📊 改进目标

确保 Top5 热点话题是：
1. **由多个 KOL 传播和讨论的真实热点话题**
2. **由多个推文聚合而成的包含关键词的话题**（hashtag、domain、cashtag）
3. **可读性强**：标题直接显示关键词，而不是"热点话题 #1"

## ✅ 已完成的改进

### 1. 过滤逻辑优化

**改进前**：
- 只要求 `unique_author_cnt >= 2` 或 `tweet_cnt >= 2`
- 没有检查是否包含关键词
- 导致 Top5 中出现只有 `center_tweet` 的话题（Rank 4, 5）

**改进后**：
- **第一优先级**：至少 2 个 KOL + 至少 2 条推文 + 包含关键词（hashtag/domain/cashtag）
- **第二优先级**：至少 1 个 KOL + 至少 2 条推文 + 包含关键词
- **不再补充**：如果符合条件的不足 5 个，宁愿 Top5 少于 5 个，也要确保质量

### 2. HotScore 计算优化

**新增关键词奖励机制**：
```python
keyword_bonus = 1.0 + 0.5 * log1p(keyword_count) if has_keywords else 0.5
```

- 有关键词的话题：获得 1.0 + 0.5 * log1p(keyword_count) 的奖励
- 没有关键词的话题：降权到 0.5 倍

这确保了有关键词的真实话题会获得更高的 HotScore。

### 3. 标题生成改进

**改进前**：
- 标题：`热点话题 #1（48 个相关主题聚合）`
- 无法直接看出话题内容

**改进后**：
- 从 `member_topics` 中提取关键词（hashtag、domain、cashtag）
- 标题直接显示关键词：`#geminienterprise, x.com, Tryinspector.com 等 4 个关键词`
- 如果没有关键词，才使用默认标题

### 4. 关键词信息保存

每个话题现在都包含 `keywords` 字段：
```json
{
  "keywords": {
    "hashtags": ["geminienterprise"],
    "domains": ["x.com", "Tryinspector.com", "science.nasa.gov"],
    "cashtags": [],
    "all_keywords": ["#geminienterprise", "x.com", "Tryinspector.com", "science.nasa.gov"]
  }
}
```

### 5. 描述信息增强

描述现在包含关键词信息：
- `聚合了 48 个相关主题，5 位 KOL 参与讨论，共 49 条推文。标签: #geminienterprise；域名: x.com, Tryinspector.com, science.nasa.gov`

## 📈 改进效果对比

### 改进前
- **Top5 数量**：5 个
- **符合要求的话题**：2 个（Rank 1, 3）
- **问题**：
  - Rank 4, 5：0 个 KOL，无关键词
  - Rank 2：无关键词（只有 center_tweet）
  - 标题不够具体

### 改进后
- **Top5 数量**：2 个（质量优先）
- **符合要求的话题**：2 个（100%）
- **优势**：
  - ✅ 所有话题都有多个 KOL 参与（≥2）
  - ✅ 所有话题都包含关键词（hashtag/domain/cashtag）
  - ✅ 标题直接显示关键词，可读性强
  - ✅ 描述包含关键词信息

## ✨ 核心改进理念

**质量优先于数量**：
- 宁愿 Top5 只有 2-3 个高质量话题，也不要 5 个低质量话题
- 确保每个话题都是"多个 KOL 讨论的真实热点话题"
- 确保每个话题都包含可识别的关键词（hashtag/domain/cashtag）
