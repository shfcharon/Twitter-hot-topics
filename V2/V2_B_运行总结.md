## 发现的问题

### 1. 标题生成不够理想
- **问题**: 很多议题的标题是"热点议题 1"、"热点议题 3"等默认标题
- **原因**: 中心实体提取不够好，很多社区没有提取到实体
- **改进方向**: 
  - 改进实体提取逻辑（使用 NER 模型）
  - 改进中心实体识别（考虑更多因素）

### 2. 实体提取不足
- **问题**: 很多议题的 key_entities 都是空的
- **原因**: 
  - 实体提取方法过于简单（只匹配常见公司名列表）
  - 很多推文没有包含可识别的实体
- **改进方向**: 
  - 使用 NER（命名实体识别）模型
  - 扩展实体类型（产品名、技术名等）

### 3. 社区发现结果
- **问题**: 很多议题只有1个作者
- **原因**: 
  - 数据量较小（只有113条推文）
  - 社区发现算法可能需要调整参数
- **改进方向**: 
  - 调整社区发现算法的参数（resolution）
  - 考虑使用更先进的社区发现算法（如 Leiden）

## 下一步改进方向

### 短期改进
1. **改进实体提取**：
   - 使用 NER 模型提取更多实体
   - 扩展实体类型（产品名、技术名、事件类型等）

2. **改进标题生成**：
   - 当没有中心实体时，使用推文内容生成标题
   - 使用 LLM 生成更清晰的标题

3. **改进中心节点识别**：
   - 考虑更多因素（如 PageRank、Betweenness Centrality）
   - 改进中心度计算

### 长期改进
1. **使用更先进的社区发现算法**：
   - 安装并使用 `networkx` 和 `leidenalg`
   - 使用标准的 Louvain 或 Leiden 算法

2. **改进图结构**：
   - 添加更多节点类型（如产品、技术等）
   - 添加更多边类型（如语义相似度边）

3. **使用 LLM 生成描述**：
   - 使用 LLM 分析社区内容，生成更清晰的标题和描述
   - 回答"发生了什么"、"有什么影响"等问题
